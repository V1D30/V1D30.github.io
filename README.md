# V1D30 — My First Website

A beginner-friendly personal website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — the page content
- `style.css` — colours, layout, responsive design, and animation
- `script.js` — closes the mobile menu and keeps the footer year current
- `.nojekyll` — tells GitHub Pages to serve the files directly

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named `V1D30.github.io`.
2. Upload all four website files from this folder to the repository root.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. After GitHub finishes publishing, visit `https://v1d30.github.io`.

## Make it yours

Open `index.html` in a text editor to change the words. Open `style.css` to change the colours and layout. Commit your changes to GitHub and the live site will update automatically.
